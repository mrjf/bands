# @bands/editor

> **Experimental.** This package is under active development. Its API and UI are unstable.

Visual editor for BAND.md files. Web UI built with Web Components.

## Development

```bash
bun run dev       # Start dev server
```

## Building

```bash
bun run build           # Full build (client + server)
bun run build:client    # Build browser app only
```

## Running

```bash
bun run start     # Run production server
```
